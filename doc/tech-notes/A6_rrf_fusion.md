# RRF 倒数排名融合

## 是什么
RRF（Reciprocal Rank Fusion）是一种把多个检索列表融合成一个排序结果的算法，只看「排名」不看「分数绝对值」：

```
score = Σ 1 / (k + rank_i)
```
`k` 是平滑常数（常取 60）。每个候选文档在各路检索里的排名越靠前，融合分越高。

## 为什么用它而不是加权求和
不同检索路的分数量纲完全不同（稠密向量是余弦 0–1，稀疏向量是 IP 可能上千），直接加权求和要先归一化、还敏感。RRF 只用排名，天然免疫量纲差异，鲁棒且无需调权重。

## 与本项目的关系
`node_rrf` 把多路候选融合：
- Milvus 稠密检索 TopN
- Milvus 稀疏检索 TopN
- Web Search MCP 结果
- （可选）Neo4j 知识图谱结果

融合后输出统一排序，再交给 `node_rerank` 精排。对应技术问答，融合让「语义命中 + 关键词命中 + 网络补充」不会出现某一路独大。

## 调参
- `k` 越大，排名靠后的文档影响越大；默认 60 够用；
- 各路召回的 TopN 要一致（如都取 20），否则短列表的文档天然吃亏。
