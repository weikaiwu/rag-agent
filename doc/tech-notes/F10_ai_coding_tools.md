# AI 编程工具提效（Claude Code / Cursor 等）

## 是什么
AI 编程助手（Cursor、Claude Code、Copilot、Windsurf）把 LLM 接进开发流程：补全代码、解释报错、改文件、跑命令、甚至自主完成一个子任务。2025–2026 主流团队的工程规范里，「熟练使用 AI 编程工具」已从加分项变成默认要求——不是因为它代替程序员，而是因为它放大产出。

## 主流形态
- **Copilot**：行内补全；
- **Cursor / Windsurf**：AI 原生编辑器，能跨文件改、问答；
- **Claude Code / Codex CLI**：终端里的 Agent，能读库、改文件、跑测试、自循环修 bug。

## 怎么用才值
- 让它解释陌生代码、写样板、生成测试；
- 复杂架构仍要人来定，AI 当「高级实习生」；
- 关键：给它清晰上下文（如 CLAUDE.md 写项目约定），产出才准。

## 与本项目的关系
本项目在 AI 编程工具辅助下完成：补 Neo4j 图谱召回、接入 RAGAS 评估、补 TTFT 埋点、修 SSE 流式推送 bug，均按「人定位问题、工具改代码、人验结果」的方式推进。实践下来的边界很清楚——架构选型、取舍判断、验收标准必须人来定，样板代码、测试、报错解释交给工具。

## 注意
- AI 生成的代码必须 review，尤其安全/边界；
- CLAUDE.md 写清项目约定，比反复口头交代高效。
