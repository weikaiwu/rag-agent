# Prompt 工程

## 是什么
Prompt Engineering 是通过设计输入文本，引导 LLM 稳定产出想要结果的技术。不是改模型，是改「怎么问」。

## 常用技巧
- **角色设定（Role）**：「你是资深 RAG 工程师」，定语气和边界；
- **Few-shot**：给 1–3 个示例，模型照着学格式；
- **结构化输出**：要求返回 JSON / 指定字段，方便程序解析；
- **思维链（CoT）**：「一步步思考」，提升复杂推理；
- **约束与负面指令**：「不要编造来源」「只基于上下文回答」。

## 与本项目的关系
项目里有多个 `.prompt` 文件（独立管理，方便调）：
- `answer_out.prompt`：约束生成答案「只基于检索上下文、引用来源、不编造」；
- `rewritten_query_and_itemnames.prompt`：把口语问题改写成检索友好形式 + 抽取主题；
- `item_name_recognition.prompt`：从文档抽取技术主题（实体识别口径，输出规范的技术概念）；
- `kg_extraction.prompt`：抽取实体关系建知识图谱。

## 经验
- 负面约束比正面要求更管用（「不要…」常比「要…」有效）；
- 复杂任务用结构化输出 + 后处理校验；
- prompt 也要评估驱动迭代，别一次写死。
