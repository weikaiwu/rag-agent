# Function Calling 与 Tool Use（工具调用）

## 是什么
Function Calling（函数调用 / Tool Use）让 LLM 能「调用外部函数」而不是只吐文本：模型输出一个结构化调用请求（函数名 + 参数 JSON），宿主程序执行真实函数（查数据库、调 API、算数），再把结果喂回模型继续生成。这是 Agent 能「动手」的基础。

## 工作流程
1. 给模型一份「工具清单」（JSON Schema 描述每个函数的名字、参数、用途）；
2. 模型判断要不要调工具、调哪个、参数是什么；
3. 程序执行函数，拿到结果；
4. 结果作为新消息回给模型，模型据此生成最终回答。

## 与本项目的关系
本项目的 Web Search MCP 本质就是工具调用：查询图在「网络搜索」环节，通过 MCP 协议让模型决定搜索什么关键词，外部搜索服务返回结果，再融入上下文。MCP 是 Function Calling 的标准化封装（见 F4/B4）。

## 常见坑
- 参数 schema 写得不清楚 → 模型传错参；
- 工具返回太大 → 占上下文，要截断或摘要；
- 模型「幻觉调用」不存在的工具 → 要严格校验函数名白名单。
