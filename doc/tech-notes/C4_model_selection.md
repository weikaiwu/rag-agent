# 主流大模型怎么选

## 是什么
做 AI 应用第一件事是选底座模型。2025–2026 主流分几类：闭源旗舰、开源可私有化、国产 API。

## 主流对比
| 类别 | 代表 | 特点 | 适用 |
|------|------|------|------|
| 闭源旗舰 | GPT-4o / Claude | 能力强、贵、数据出公网 | 不敏感任务 |
| 国产 API | 通义千问 / DeepSeek / 智谱 | 中文好、合规、便宜 | 国内业务首选 |
| 开源私有化 | Qwen / DeepSeek 本地部署 | 数据不出门、可微调 | 有合规/数据要求 |

## 选型维度
- **能力**：复杂推理选旗舰或 DeepSeek-R1 类；
- **成本**：高并发选国产 API 或本地；
- **合规**：数据敏感必须私有化或国产；
- **延迟**：流式场景选响应快的（看 TTFT）；
- **上下文窗口**：长文档选大窗口模型。

## 与本项目的关系
本项目通过 `.env` 配置模型（OpenAI 兼容接口），可无缝切到 DeepSeek / 通义。embedding 用 BGE-M3（开源、可本地），reranker 用 BGE-reranker，生成模型可配置。整个管道「模型可插拔」。

## 注意
- 别盲目追旗舰，RAG 场景 retrieval 质量常比模型档位影响更大；
- 切换模型要重测 RAGAS，不同模型 faithfulness 差异明显。
