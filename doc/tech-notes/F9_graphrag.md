# GraphRAG（知识图谱增强 RAG）

## 是什么
GraphRAG 是微软 2024 提出的 RAG 进阶范式：先对文档做**实体/关系抽取**建成知识图谱（KG），检索时**同时走「向量检索」和「图遍历」**两路——向量抓语义片段，图谱抓「A 和 B 什么关系、某实体的上下游链路」。特别适合需要「全局性、多跳推理」的问题（"某公司的主要供应商有哪些风险"）。

## 为什么比纯向量 RAG 强
- 纯向量：找相似片段，难回答「关系型/汇总型」问题；
- GraphRAG：图谱能沿关系跳好几跳，把分散信息连成答案。

## 与本项目的关系（重点）
本项目**已经实现了 Neo4j 知识图谱模块**（env 门控、留空则安全跳过）：
- 导入图 `node_build_kg`：用 LLM 抽取实体关系写入 Neo4j；
- 查询图 `node_query_kg`：作为**第 4 路召回源**，结果进 RRF 融合。
这正好就是 GraphRAG 的「向量 + 图谱」双路思想，是项目差异化卖点。

## 注意
- 建 KG 成本高（要 LLM 抽取），文档量大时慢；
- 不是所有场景都需要图谱，关系型问题才值；
- 本项目 KG 为可选增强，主检索仍是向量混合检索。
