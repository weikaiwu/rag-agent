# Agent Skill（技能封装）

## 是什么
Skill（技能）是把「一段可复用的能力」封装成 Agent 能直接调用的单元——比裸工具（Function Calling）高一层：Skill 可以包含「触发条件 + 步骤 + 自带工具 + 自带提示词」，让 Agent 遇到某类任务自动启用。类比：工具是「一个函数」，Skill 是「一套方法论」。

## 与 Function Calling 的区别
- Tool：模型调一个函数，输入输出明确；
- Skill：模型识别「这类任务该用这套流程」，自动加载对应的提示词/子流程/工具集。更接近「人的某项专业技能」。

## 行业动态
2025–2026 多家把 Skill 当作 Agent 生态的一等公民：Anthropic 的 Claude 有 skill 机制，开源框架也普遍支持「可插拔 skill」。工程落地中，「Skill + MCP + Tool」三层已是常见的能力组织方式。

## 与本项目的关系
本项目的「主题确认」「HyDE 检索」「重排截断」都可视为领域 Skill 的雏形——把一类处理逻辑固化成可复用单元。若抽象成 Skill 体系，能让新领域（换知识库）快速接入：换 Skill 配置而非改代码。

## 设计要点
- Skill 要有清晰触发描述，避免误触发；
- Skill 内可组合多个 tool；
- Skill 要可独立测试。
